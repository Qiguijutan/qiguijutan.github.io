# 图像颜色聚类可视化系统

> 数据可视化课程作业 | 基于 K-means 的图片主色提取与交互式分析

本项目实现了一个**完全在前端运行**的图片颜色聚类可视化工具。用户可以上传图片或选择内置示例，通过 K-means 算法对像素颜色进行聚类（K≥5），并以柱状图/饼图展示聚类中心的颜色及像素数量。支持 RGB/LAB 颜色空间切换、动态调整聚类数 K，并可调用大语言模型 API 对聚类颜色的和谐度进行智能评价。

🔗 **在线访问**：https://qiguijutan.github.io/ 

---

## 功能特性

### 基本要求
- ✅ **K-means 聚类**：对图片所有像素进行颜色聚类（K 值可调，默认 K≥5）
- ✅ **可视化双维度**：
  - 聚类中心的颜色（RGB 值及色块展示）
  - 每类包含的像素数量（绝对数量及百分比）
- ✅ **ECharts 图表展示**：支持柱状图（Bar）与饼图（Pie）两种样式
- ✅ **聚类中心色板**：直观显示各类主色及像素占比

### 进阶特性
- ✅ **可交互选择 K 值**：滑块动态调整（5~16），实时重新聚类
- ✅ **可交互切换图片**：支持上传本地图片或选择内置示例（3 种风格）
- ✅ **可切换可视化样式**：一键在柱状图和饼图之间切换
- ✅ **可切换颜色空间**：支持 RGB 与 LAB 色彩空间，提高聚类准确性
- ✅ **AI 颜色和谐度分析**：调用大语言模型接口（兼容 OpenAI/CloseAI-Asia），判断聚类颜色组合是否和谐（支持模拟模式演示）

## 技术栈

- **前端**：原生 HTML5 / CSS3 / JavaScript (ES6)
- **可视化**：ECharts 5.4.3
- **聚类算法**：K-means++ 初始化 + 欧氏距离迭代
- **颜色空间转换**：RGB ↔ LAB（D65 标准）
- **AI 接口**：OpenAI 兼容 API（支持 closeai-asia 等平台）

### 1. 在线使用（推荐）
直接访问 GitHub Pages 链接：https://qiguijutan.github.io/

3. **执行聚类**：点击“立即聚类”或修改参数自动触发

5. **AI 和谐度分析**（可选）：

## 算法核心

### K-means 聚类流程
1. **像素采样**：限制图片最大面积（400×400），保证性能
2. **颜色空间转换**：根据用户选择将 RGB 转为 LAB（可选）
3. **K-means++ 初始化**：优化初始中心点选择
4. **迭代分配与更新**：欧氏距离分配 + 均值更新中心（最大迭代 40 次）
5. **结果输出**：聚类中心 RGB 值、每类像素数量

### LAB 空间优势
LAB 颜色空间更接近人眼感知，欧氏距离能更好区分颜色差异，适合颜色聚类任务。

## AI 和谐度分析

- **接口兼容**：支持 `https://api.closeai-asia.com/v1/chat/completions` 等 OpenAI 风格接口
- **请求格式**：
  ```json
  {
    "model": "gpt-3.5-turbo",
    "messages": [{"role": "user", "content": "分析这些颜色是否和谐：rgb(255,0,0), rgb(0,255,0)..."}]
  }
  ```
- **模拟模式**：未提供 API Key 时，前端模拟生成评价，便于功能演示

> 注意：调用真实 API 需自行获取有效 Key，并确保网络可访问接口地址。
